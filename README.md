## 🆘 Troubleshooting Common Problems

### The server won't start
- Make sure you downloaded the correct file for your Windows version (64-bit vs 32-bit).
- Try right-clicking the file and selecting "Run as administrator" if it will not open normally.
- Check if your antivirus is blocking it. If so, allow the program through.

### MAME does not connect to the server
- Ensure MAME is running before you start the CoCo3 MCP Server, or restart it after starting the server.
- Check that you are running MAME with the CoCo3 emulation mode (coco3).
- Make sure no other program is using the port that the server needs (default is 8080).

### Programs do not see the server
- Verify that the server window shows "Listening" or "Connected" status.
- Restart both the server and your MCP client application.
- Look for any firewall pop-ups and allow access.

### Everything worked once, but now it does not
- Try restarting your computer.
- Re-download the server file in case it got corrupted.
- Reset MAME to default settings.
